# Qt UI Copilot V3 使用指南

## 启动 V3

V3 是默认 Renderer。旧 V2 兼容入口可使用 `QT_UI_COPILOT_V2=1`。

## 基本流程

1. 点击“打开文件夹”，选择 Qt 项目根目录。
2. 在 Explorer 中单击或双击 `.ui` 文件打开 Tab。
3. 选择“快速预览”查看基础 UI，或选择“增强预览”加载 QSS、QRC、字体和 Designer 插件。
4. 在右侧 AI Assistant 输入界面需求。
5. 在“专注界面”和“整体模式”之间选择上下文范围。
6. 默认使用审批模式；确认计划后点击“审批并应用”。设置为自动应用后，仍会执行 XML、语义、uic 和预览校验。
7. 修改失败时原文件保持不变；Revision 支持撤销和重做。

## 预览可信度

增强预览会显示资源加载、降级项和可信度。自定义控件插件缺失时会使用基类占位，不能将其当作真实业务运行结果。需要最终确认时，在底部 Runtime 面板执行真实 EXE、QtUiProbe 和语义路线验证。

## 上下文安全

专注界面模式只读取当前 `.ui`、相关资源和组件候选。AI 需要读取 C++ 或头文件时会产生读取请求；整体模式允许在项目内检索，但首版只自动写入 `.ui`。

## 创建全新界面

当项目中还没有合适的 `.ui` 文件时，可以在右侧 AI Assistant 切换到“创建新界面”模式。该模式不会修改当前文件，而是先生成一个可审查的草稿候选。

1. 打开 Qt 项目文件夹；如果没有项目，也可以先创建或选择一个空的 Qt Widgets 项目目录。
2. 将 PNG、JPEG、WEBP 或 SVG 参考图拖入 AI Assistant，或者点击“选择附件”。拖入图片后，在尚未打开 `.ui` 文件时会自动切换到创建模式。
3. 可同时拖入 `.ui`、`.qss`、`.qrc`，以及用户明确选择的 `.h`、`.hpp`、`.cpp` 等文件作为参考。源码不会因为图片附件而自动读取。
4. 填写新 UI 文件名（必须以 `.ui` 结尾）、保存目录、根窗口类型（`QWidget`、`QDialog` 或 `QMainWindow`）和界面需求。
5. 选择是否使用项目 QSS/QRC 和组件库，然后点击“生成界面草稿”。
6. AI 返回的是结构化 `UiCreationBlueprint`，Main 进程使用确定性生成器生成 `.ui` XML，并执行 XML、语义、`uic` 和预览校验。
7. 在草稿卡片中检查预览与校验结果。点击“放弃草稿”只丢弃候选；点击“审批并保存”后才会写入项目，并自动在新的 Tab 中打开。

如果目标文件已经存在，系统会拒绝覆盖并保留原文件。生成或校验失败时也不会创建半成品；可以修改需求、文件名或附件后重新生成。图片最多 4 张，单个附件最多 10 MB，全部附件最多 24 MB。

创建模式和“修改当前界面”模式共享同一套审批、校验和预览能力。创建新界面采用两阶段流程：第一阶段生成稳定的基础布局并执行 `uic` 校验；第二阶段逐项增强字体、尺寸、QSS 和资源。视觉增强失败时只跳过该项，保留最近一次有效候选。

生成面板会显示当前阶段和已完成步骤。基础候选通过 `uic` 后即可保存，不需要等待所有视觉增强完成。错误卡片会区分可重试的模型服务问题、可降级的预览问题和阻断保存的 Qt 校验问题，并提供继续重试、查看详情和复制诊断操作。被跳过的增强项会进入 Problems 面板，便于后续从对话中继续处理。
