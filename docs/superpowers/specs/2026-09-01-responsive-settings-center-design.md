# 响应式设置中心设计

## 目标

将设置从左侧窄栏迁移到中央工作区 Tab，消除模型配置与项目配置在窄宽度下的字段挤压、文字断行和按钮重叠。设置页采用响应式分类导航和单列优先表单，同时保留现有配置读写、能力检测和安全存储语义。

## 信息架构

点击活动栏“设置”时，在中央成果工作区打开唯一的 `设置` Tab；左侧栏保持当前文件树或任务历史，不再承载设置内容。

设置 Tab 内部分类：模型服务、Qt Kits、构建工具、项目绑定、预览与资源、启动与导航、组件来源、外观、数据与安全。

宽度规则：

- 宽度大于等于 900px：左侧分类导航 + 右侧内容区。
- 宽度 640px 至 899px：顶部横向分类导航 + 单列内容区。
- 宽度小于 640px：顶部 `select` 分类选择器 + 单列内容区。

分类切换不能丢失未保存输入内容。

## 模型服务布局

模型服务拆为三个卡片区块：

1. 连接：Base URL、模型、API Key 和保存操作。
2. 图像：图片发送格式及简短说明。
3. 能力检测：文本、JSON、视觉三项检测。

连接区在宽度大于等于 900px 时允许 Base URL 与模型并排；低于该阈值时所有字段改为全宽单列。API Key 始终独占一行。`Key 已配置` 显示为标题旁的小型状态徽章。

能力检测每项使用名称、当前状态和操作按钮。宽度大于等于 640px 时按钮右对齐；小于 640px 时按钮换行并全宽。失败信息默认显示一行摘要，详情通过可展开按钮展示。

## 项目配置布局

构建工具、预览与资源、启动与导航页面使用分组折叠区。每个分组只展示当前需要的字段，长列表使用可增删的行项或多行输入，不与不相关配置同时平铺。

保存操作放在设置内容底部的粘性操作栏，滚动时保持可见。保存和检测结果显示为页内状态提示，避免使用遮挡表单的浮层。

## 视觉规则

- 继续沿用中性灰深色主题。
- 降低无意义边框和大圆角的数量；卡片只用于分组边界。
- 标题层级缩小，避免窄宽度下大标题占据过多空间。
- 表单标签位于字段上方，说明文本位于字段下方。
- 状态使用小徽章、单色图标和短文本；红黄绿只用于语义状态。
- 所有文字允许自然换行，输入和按钮不得产生横向溢出。

## 验证标准

- 点击活动栏设置后，中央出现唯一设置 Tab，左侧文件树不被替换。
- 360px、640px、900px 宽度下，模型服务的字段和按钮均不重叠、不横向溢出。
- 在分类切换后，未保存的模型设置和项目字段保持原值。
- 文本、JSON、视觉能力检测保持可用；失败摘要与详情均可访问。
- 保存操作在长项目设置页面滚动后仍可见。
- 现有模型配置、Qt Kit、项目绑定、预览资源与数据安全测试继续通过。
