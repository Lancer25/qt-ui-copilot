# 组件库开关图标对齐设计

## 目标

修复任务输入区“组件库 / 引用”开关中图标相对文字偏低的问题，使图标、主标签和状态标签在同一视觉中线上。

## 方案

- 保留现有按钮结构、尺寸、颜色和交互，不进行功能调整。
- 图标容器改为固定方形的 `inline-flex`，使用 `align-items` 与 `justify-content` 居中。
- 消除图标字符自身行盒导致的垂直偏移，统一 `line-height`，并用轻量视觉位移补偿字体字形中心。
- 按钮内主文字和状态标签均使用统一的 flex 垂直居中规则。

## 验收

- 图标、组件库文字与“引用/忽略”标签视觉中线一致。
- 开启和关闭状态均不跳动。
- 1366、1100 和常规桌面宽度下按钮不变形、不截断。
- 现有 TaskComposer 测试与类型检查继续通过。
