# 组件库开关图标对齐设计

## 目标

修复任务输入区“组件库 / 引用”开关中图标相对文字偏低的问题，使图标、主标签和状态标签在同一视觉中线上。

## 根因

现有图标使用文本字符 `⊞`。Windows 字体中的该字形可见轮廓并不位于字符行盒的几何中心，因此 Flex 只能对齐字符盒，无法对齐用户实际看到的图形；通过 `padding` 或 `translate` 补偿也会随字体与 DPI 改变。

## 方案

- 保留现有按钮尺寸、颜色和交互，不进行功能调整。
- 将文本字符替换为项目现有 `WorkspaceIcon` 的 `components` SVG 图标，复用活动栏一致的四宫格图形。
- 图标容器维持固定方形的 `inline-flex`，SVG 使用明确宽高，不再依赖字体行盒或像素位移。
- 删除之前针对 `⊞` 的字体、底部内边距和字形补偿规则。
- 按钮内主文字和状态标签均使用统一的 flex 垂直居中规则。

## 验收

- 图标、组件库文字与“引用/忽略”标签视觉中线一致。
- 开启和关闭状态均不跳动。
- Windows 100% 和 125% DPI 下均保持居中。
- 1366、1100 和常规桌面宽度下按钮不变形、不截断。
- 现有 TaskComposer 测试与类型检查继续通过。
