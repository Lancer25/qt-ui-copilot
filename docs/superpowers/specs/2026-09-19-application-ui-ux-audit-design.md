# Qt UI Copilot 全应用 UI/UX 优化设计

## 目标

在保留现有活动栏、上下文侧栏、标签页和主工作区信息架构的前提下，统一 Qt UI Copilot 的视觉层级、交互反馈和页面密度。优化覆盖窗口框架、AI 任务、项目浏览器、组件库、预览、源码、任务历史和设置页，并在 1366×768、1600×1000 与窄窗口下保持可用。

## 审查基线

桌面审查基于九个真实 Electron 页面截图：AI 空任务、组件库、组件展开、任务历史、模型设置、组件源设置、项目浏览器、UI 预览和源码页。

主要问题：

- 设置页打开后活动栏仍高亮之前的区域，并保留无关上下文侧栏。
- AI 空任务页面留白过大，标题和输入区缺少稳定的上下结构。
- 组件卡片标题、来源和状态互相争抢宽度，滚动浏览效率低。
- 无 Qt Kit 的组件预览暴露 Electron IPC 原始错误。
- 设置来源状态徽标过大，表单和状态卡片层级偏重。
- 系统原生灰色滚动条与暗色主题不协调。
- 源码页缺少文件路径、行号、复制动作和只读标识。
- 空任务历史缺少明确的下一步入口。
- 页面内容宽度、边距、按钮高度、空状态和错误反馈不一致。

## 统一设计系统

### 尺寸与密度

- 活动栏固定 56px。
- 常规上下文侧栏使用 `clamp(248px, 19vw, 296px)`。
- 设置页隐藏上下文侧栏，主区域占满活动栏之外的宽度。
- 主内容最大宽度分为 960px（表单/任务）和 1180px（设置/预览）。
- 普通控件高度统一为 34px，主要按钮为 36px，紧凑图标按钮为 30px。
- 页面间距使用 4、8、12、16、24、32px 阶梯。

### 颜色与状态

- 保留当前深色基础和蓝色强调色。
- 状态仅使用紧凑徽标：成功绿色、警告琥珀、失败红色、处理中蓝色。
- 选中状态使用背景与左侧强调线；键盘焦点使用独立 2px focus ring。
- 禁用状态降低对比但保持文字可辨认。

### 滚动条与提示

- 应用内滚动区域统一使用 8px 暗色滚动条和圆角滑块。
- Tooltip 提供完整标题、图标含义和截断文本。
- 原始 IPC/Node 错误不得直接显示；统一提取用户可理解的信息和下一步操作。

## 窗口框架与导航

- 设置活动被选择时，活动栏正确高亮设置图标。
- 设置页不显示项目、任务历史或搜索侧栏，工作区网格切换为无侧栏模式。
- 从设置返回其他活动时恢复对应侧栏。
- 标签页保持可关闭，活动标签使用底部强调线和更清晰文字对比。
- 侧栏与主区域各自滚动，避免全窗口出现重复滚动条。

## AI 任务页面

- 空任务采用“介绍区 + 建议提示 + 底部输入器”结构。
- 标题区位于内容上半部，输入器固定在可视区域底部附近，而不是悬浮在几何中心。
- 增加三条可点击的示例提示：创建登录页、优化当前界面、编译运行项目。
- 输入器保持最大宽度 960px，附件区、文本区和选项区形成明确层级。
- 运行中、排队、停止和发送状态保持现有语义。

## 组件库

- 搜索与来源筛选置于粘性头部，列表独立滚动。
- 卡片标题最多一行并提供 `title`；来源使用紧凑徽标，不再在右侧多行显示“来自…”文字。
- 依赖状态、来源和选中状态各自分工，不重复表达。
- 展开详情继续使用预览优先设计，但控制总体高度，描述最多两行。
- 组件预览错误通过统一解析器去除 `Error invoking remote method ...` 前缀。
- 未配置 Qt Kit 时显示“需要配置 Qt Kit”及“打开设置”动作；其他失败显示简短原因和重试。

## 任务历史

- 空状态使用图标、标题、说明和“开始新任务”按钮。
- 历史项使用一致的状态徽标、相对时间和选中状态。
- 已终止但仍标为运行中的快照继续由已有恢复逻辑纠正。

## 设置页

- 隐藏无关上下文侧栏，设置分类和内容居中于主区域。
- 页面头部压缩高度，分类导航保持 216px 左列。
- 组件来源卡片改为紧凑两列布局：来源信息、同步信息、状态徽标和操作按钮对齐。
- “可用”状态改为小型圆角徽标，不使用纵向大椭圆。
- 表单标签、说明、输入框和保存栏统一尺寸。
- 长页面保存操作可见且不遮挡内容。

## 项目浏览器

- 工具栏、筛选框和树之间使用明确分隔。
- 文件图标、展开箭头、修改/错误状态和选中背景保持一致。
- 截断路径和文件名提供 title。
- 关闭文件夹动作仅在项目存在时可见。

## UI 预览

- 工具栏按“渲染模式 / 尺寸 / 窗口”分组，小窗口时允许换行。
- 预览画布占据主要空间，空状态和失败状态居中并提供单一主动作。
- AI 调整输入器保持底部稳定，不覆盖预览或审批栏。
- 原始大小、自适应和独立窗口状态保持现有正确行为。

## 源码页

- 增加文件工具栏：完整路径、只读徽标和“复制全部”按钮。
- 使用独立行号列与代码列，保持同步滚动。
- 代码字体、行高和选区对比优化；长行允许水平滚动。
- 读取失败使用统一错误卡，不显示裸文本异常。

## 通用反馈

- 空状态、加载、错误、成功统一使用相同卡片骨架。
- Toast 默认 4 秒后消失，支持手动关闭；关键错误保留到用户处理。
- 所有图标按钮提供 `aria-label` 和 tooltip。
- 所有交互支持键盘 Tab、Enter、Space 和可见焦点。

- 新增设置来源紧凑状态测试。
