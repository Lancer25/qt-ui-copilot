# V3 Toast Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the persistent bottom-right message with a short-lived, accessible top-right notification.

**Architecture:** A focused `V3Toast` component owns dismissal timing and presentation. `V3App` stores a typed notice and classifies success, informational and error call sites explicitly.

**Tech Stack:** React, TypeScript, CSS, Vitest.

**Spec:** `docs/superpowers/specs/2026-09-11-v3-toast-design.md`

## Global Constraints

- Success/info timeout: 3000 ms.
- Error timeout: 8000 ms.
- Manual close is always available.
- Notification must not cover preview controls or composer actions.

### Task 1: Component and lifecycle

- [ ] Add `V3Toast.tsx` and tests for both timeout values and manual dismissal.
- [ ] Replace the persistent string state in `V3App` with a typed notice and explicit severity.
- [ ] Add top-right positioning, entry animation, status colors and reduced-motion handling.
- [ ] Run focused renderer tests, typecheck, and package the portable build.
